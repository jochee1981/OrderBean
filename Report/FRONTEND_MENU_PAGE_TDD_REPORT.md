## 구현된 기능

### 1. Header (헤더)

- **관리자 버튼**: 관리자 권한이 있을 때만 표시 (보라색 배경)
- **로그인/로그아웃**: 사용자 상태에 따라 표시

### 2. 메뉴 카드
- **레이아웃**: 그리드 레이아웃 (반응형)
  - Desktop: 3열
  - Tablet: 2열
  - Mobile: 1열
- **메뉴 정보**:
  - 메뉴명
  - 가격 (천 단위 구분 기호 포함)
  - 담기 버튼

### 3. 장바구니
- **항목 목록**: 선택된 메뉴와 수량 표시
- **총 금액**: 모든 항목의 총합 계산 및 표시
- **주문하기 버튼**: 장바구니에 항목이 있을 때만 활성화
- **빈 장바구니 메시지**: 항목이 없을 때 안내 메시지 표시

### 4. 상태 관리
- **Zustand 사용**: 경량 상태 관리 라이브러리
- **장바구니 기능**:
  - 항목 추가
  - 항목 제거
  - 수량 업데이트
  - 총 금액 계산
  - 장바구니 비우기
