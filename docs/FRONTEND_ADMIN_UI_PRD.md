## 1. 개요

### 1.1 목적
OrderBean 관리자 화면은 카페 운영자가 주문을 모니터링하고, 재고를 관리하며, 주문 상태를 업데이트할 수 있는 웹 인터페이스입니다.

### 1.2 주요 기능
- 주문 현황 모니터링 및 관리
- 주문 상태 업데이트 (접수, 제조 중, 제조 완료)
- 재고 현황 조회 및 수정
- 주문 통계 대시보드
- 실시간 주문 알림

### 1.3 디자인 원칙
- **효율성**: 빠른 주문 처리와 상태 업데이트
- **명확성**: 주문 정보와 상태가 한눈에 보이도록
- **즉각성**: 실시간 업데이트와 즉각적인 피드백
- **일관성**: 사용자 화면과 통일된 디자인 언어

## 2. 화면 구성

### 2.1 전체 레이아웃

```
┌─────────────────────────────────────────┐
│ Header (고정)                            │
│ [COZY]              [주문하기] [관리자]  │
│                          (선택됨)        │
├─────────────────────────────────────────┤
│                                         │
│ Main Content Area (스크롤 가능)          │
│ ┌───────────────────────────────────┐ │
│ │ 관리자 대시보드                    │ │
│ │ 총 주문 1 | 주문 접수 1 | 제조 중 0 │ │
│ │ 제조 완료 0                        │ │
│ └───────────────────────────────────┘ │
│                                         │
│ ┌───────────────────────────────────┐ │
│ │ 재고 현황                          │ │
│ │ [아메리카노(ICE) 10개] [+][-]      │ │
│ │ [아메리카노(HOT) 10개] [+][-]      │ │
│ │ [카페라떼 10개] [+][-]             │ │
│ └───────────────────────────────────┘ │
│                                         │
│ ┌───────────────────────────────────┐ │
│ │ 주문 현황                          │ │
│ │ [주문 목록]                        │ │
│ │ 7/31 13:00 | 아메리카노(ICE) x1   │ │
│ │ 4,000원 | [주문 접수]              │ │
│ └───────────────────────────────────┘ │
│                                         │
└─────────────────────────────────────────┘
```

### 2.2 화면 구성 요소

#### 2.2.1 Header (헤더)
- **위치**: 화면 최상단, 고정
- **구성 요소**:
  - 왼쪽: 브랜드명 "COZY" (또는 "OrderBean")
  - 오른쪽: "주문하기" 버튼, "관리자" 버튼 (선택 상태 표시)

#### 2.2.2 Admin Dashboard (관리자 대시보드)
- **위치**: 헤더 아래, 첫 번째 섹션
- **구성**: 주문 통계 요약 카드들
- **목적**: 한눈에 보는 주문 현황

#### 2.2.3 Inventory Status (재고 현황)
- **위치**: 대시보드 아래
- **구성**: 제품별 재고 수량 및 조정 버튼
- **목적**: 재고 실시간 관리

#### 2.2.4 Order Status (주문 현황)
- **위치**: 재고 현황 아래
- **구성**: 주문 목록 및 상태 업데이트 버튼
- **목적**: 주문 처리 및 상태 관리

## 3. 컴포넌트 상세 명세

- **스타일**:

  - 폰트 굵기: Bold
  - 색상: Primary Color (#1a1a1a 또는 브랜드 컬러)

  - 보더 라디우스: 8px
- **상태**: 
  - Default: 비활성화 (관리자 화면에서는 선택되지 않음)

- **기능**: 관리자 화면 유지 (현재 화면)

  - 텍스트 색상: White

- **상태**: 
  - Active: 선택됨 (관리자 화면에서 활성화)

## 5. 인터랙션 설계

### 5.1 버튼 인터랙션

#### 5.1.1 주문 접수 버튼
- **클릭 시**:
  1. 주문 상태 확인
  2. 상태 업데이트 API 호출 (PENDING → PREPARING)
  3. 로딩 상태 표시
  4. 성공 시 주문 현황 업데이트
  5. 대시보드 통계 업데이트
  6. 성공 피드백 (토스트 메시지)

#### 5.1.2 제조 완료 버튼
- **클릭 시**:
  1. 주문 상태 확인
  2. 상태 업데이트 API 호출 (PREPARING → READY)
  3. 고객에게 실시간 알림 발송 (WebSocket)
  4. 주문 현황 업데이트
  5. 대시보드 통계 업데이트

#### 5.1.3 재고 조정 버튼 (+/-)
- **+ 버튼 클릭 시**:
  1. 현재 재고 수량 확인
  2. 재고 1 증가
  3. UI 즉시 업데이트 (낙관적 업데이트)
  4. API 호출: 재고 업데이트
  5. 실패 시 롤백 및 에러 메시지

- **- 버튼 클릭 시**:
  1. 현재 재고 수량 확인
  2. 재고가 0보다 큰지 확인
  3. 재고 1 감소
  4. UI 즉시 업데이트
  5. API 호출: 재고 업데이트
  6. 실패 시 롤백 및 에러 메시지

### 5.2 실시간 업데이트

#### 5.2.1 새 주문 알림
- **WebSocket 연결**: 실시간 주문 수신
- **알림 표시**: 
  - 화면 상단에 알림 배너
  - 또는 주문 현황에 자동 추가
  - 사운드 알림 (선택사항)

#### 5.2.2 주문 상태 변경
- **자동 새로고침**: 주문 상태 변경 시 자동 업데이트
- **폴링**: WebSocket 없을 경우 5초마다 폴링

### 5.3 대시보드 업데이트

#### 5.3.1 통계 실시간 업데이트
- 주문 상태 변경 시 대시보드 통계 자동 업데이트
- 애니메이션 효과 (선택사항)

- **Desktop**: 1024px 이상

### 6.2 레이아웃 조정

#### 6.2.1 Mobile (320px ~ 767px)
- **대시보드 통계**: 
  - 2x2 그리드 또는 세로 나열
  - 카드 크기 조정
- **재고 현황**: 
  - 1열 레이아웃 (세로 나열)
  - 카드 너비: 100% - 32px
- **주문 현황**: 
  - 카드 형태로 변경
  - 버튼 크기 조정

#### 6.2.2 Tablet (768px ~ 1023px)
- **대시보드 통계**: 
  - 2x2 그리드
- **재고 현황**: 
  - 2열 그리드
- **주문 현황**: 
  - 카드 또는 리스트 형태

#### 6.2.3 Desktop (1024px 이상)
- **대시보드 통계**: 
  - 4열 가로 나열
- **재고 현황**: 
  - 3열 이상 그리드
- **주문 현황**: 
  - 테이블 형태 또는 카드 그리드

### 7.1 키보드 네비게이션
- 모든 버튼은 키보드로 접근 가능

### 7.4 포커스 표시

## 12. API 연동

### 12.1 필요한 API 엔드포인트
- `GET /api/v1/admin/dashboard`: 대시보드 통계 조회
- `GET /api/v1/admin/orders`: 주문 목록 조회
- `PATCH /api/v1/admin/orders/:id/status`: 주문 상태 업데이트
- `GET /api/v1/menus`: 메뉴 목록 조회 (재고 정보 포함)
- `PATCH /api/v1/menus/:id/stock`: 재고 업데이트

### 12.2 API 호출 타이밍
- **대시보드 통계**: 컴포넌트 마운트 시, 주문 상태 변경 시
- **주문 목록**: 컴포넌트 마운트 시, 실시간 업데이트
- **재고 조회**: 컴포넌트 마운트 시
- **재고 업데이트**: +/- 버튼 클릭 시
- **주문 상태 업데이트**: 상태 변경 버튼 클릭 시

### 12.3 WebSocket 연결
- **엔드포인트**: `ws://api.orderbean.com/ws/admin`
- **이벤트**: 
  - `order:new`: 새 주문 도착
  - `order:status-changed`: 주문 상태 변경
