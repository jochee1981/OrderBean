## 1. 개요

### 1.1 목적
OrderBean 사용자 화면은 고객이 카페 메뉴를 조회하고, 옵션을 선택하여 주문할 수 있는 웹 인터페이스입니다.

### 1.2 주요 기능
- 메뉴 목록 조회 및 표시
- 메뉴 옵션 선택 (샷 추가, 시럽 추가 등)
- 장바구니 관리
- 주문 생성

### 1.3 디자인 원칙
- **단순성**: 직관적이고 명확한 UI
- **즉각성**: 모든 액션에 즉각적인 피드백
- **일관성**: 전체 화면에서 통일된 디자인 언어
- **접근성**: 모든 사용자가 쉽게 사용 가능

## 2. 화면 구성

### 2.1 전체 레이아웃

```
┌─────────────────────────────────────────┐
│ Header (고정)                            │
│ [COZY]              [주문하기] [관리자]  │
├─────────────────────────────────────────┤
│                                         │
│ Main Content Area (스크롤 가능)          │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐ │
│ │ 제품 카드 │ │ 제품 카드 │ │ 제품 카드 │ │
│ └──────────┘ └──────────┘ └──────────┘ │
│                                         │
├─────────────────────────────────────────┤
│ Shopping Cart (고정 또는 하단 고정)      │
│ 장바구니                                │
│ • 항목 목록                             │
│ • 총 금액                               │
│ [주문하기]                              │
└─────────────────────────────────────────┘
```

### 2.2 화면 구성 요소

#### 2.2.1 Header (헤더)
- **위치**: 화면 최상단, 고정
- **구성 요소**:
  - 왼쪽: 브랜드명 "COZY" (또는 "OrderBean")
  - 오른쪽: "주문하기" 버튼, "관리자" 버튼

#### 2.2.2 Main Content Area (메인 콘텐츠 영역)
- **위치**: 헤더 아래, 장바구니 위
- **구성**: 제품 카드 그리드 레이아웃
- **스크롤**: 세로 스크롤 가능

#### 2.2.3 Shopping Cart (장바구니)
- **위치**: 화면 하단 (고정 또는 스크롤 가능)
- **표시 조건**: 장바구니에 항목이 있을 때만 표시
- **구성**: 선택된 항목 목록, 총 금액, 주문하기 버튼

## 3. 컴포넌트 상세 명세

### 3.1 Header 컴포넌트

#### 3.1.1 브랜드명
- **텍스트**: "COZY" 또는 "OrderBean"
- **스타일**: 
  - 폰트 크기: 24px (Desktop), 20px (Mobile)
  - 폰트 굵기: Bold
  - 색상: Primary Color (#1a1a1a 또는 브랜드 컬러)

#### 3.1.2 주문하기 버튼
- **기능**: 장바구니로 이동 또는 주문 페이지로 이동
- **스타일**: 
  - 배경색: Primary Color
  - 텍스트 색상: White
  - 패딩: 12px 24px
  - 보더 라디우스: 8px
- **상태**:
  - Default: 활성화
  - Hover: 배경색 약간 어둡게
  - Disabled: 장바구니가 비어있을 때 비활성화

#### 3.1.3 관리자 버튼
- **기능**: 관리자 화면으로 이동 (관리자 권한이 있는 경우에만 표시)
- **스타일**: 
  - 배경색: Secondary Color 또는 Transparent
  - 텍스트 색상: Gray
  - 패딩: 12px 24px
  - 보더 라디우스: 8px

### 3.2 Product Card (제품 카드) 컴포넌트

#### 3.2.1 카드 레이아웃
```
┌─────────────────────────┐
│ [이미지 영역]            │
│                         │
├─────────────────────────┤
│ 제품명                  │
│ 가격                    │
│ 간단한 설명...          │
│                         │
│ 옵션:                   │
│ ☐ 샷 추가 (+500원)      │
│ ☐ 시럽 추가 (+0원)      │
│                         │
│ [담기] 버튼             │
└─────────────────────────┘
```

#### 3.2.2 이미지 영역
- **크기**: 
  - Desktop: 200px × 200px
  - Mobile: 150px × 150px
- **비율**: 1:1 (정사각형)
- **스타일**: 
  - 보더 라디우스: 8px (상단만)
  - 배경색: #f5f5f5 (플레이스홀더)
- **이미지 없을 때**: 
  - 플레이스홀더 아이콘 또는 기본 이미지 표시
  - 대각선 X 표시 (와이어프레임 기준)

#### 3.2.3 제품명
- **폰트 크기**: 18px (Desktop), 16px (Mobile)
- **폰트 굵기**: Semi-bold
- **색상**: #1a1a1a
- **예시**: "아메리카노(ICE)", "아메리카노(HOT)", "카페라떼"

#### 3.2.4 가격
- **폰트 크기**: 20px (Desktop), 18px (Mobile)
- **폰트 굵기**: Bold
- **색상**: Primary Color 또는 #1a1a1a
- **형식**: "4,000원", "5,000원" (천 단위 콤마)

#### 3.2.5 설명
- **텍스트**: "간단한 설명..." (최대 2줄, 말줄임표 처리)
- **폰트 크기**: 14px
- **색상**: #666666
- **높이**: 최대 40px (2줄)

#### 3.2.6 옵션 체크박스
- **레이아웃**: 세로 나열
- **체크박스 스타일**: 
  - 크기: 20px × 20px
  - 체크 시: Primary Color 배경
- **옵션 텍스트**: 
  - 형식: "옵션명 (추가 가격)"
  - 예시: "샷 추가 (+500원)", "시럽 추가 (+0원)"
- **동작**:
  - 체크/언체크 시 가격 실시간 업데이트 (선택사항)
  - 여러 옵션 선택 가능 (allowMultiple이 true인 경우)

#### 3.2.7 담기 버튼
- **텍스트**: "담기"
- **스타일**: 
  - 배경색: Primary Color
  - 텍스트 색상: White
  - 폰트 크기: 16px
  - 패딩: 12px 24px
  - 보더 라디우스: 8px
  - 너비: 100%
- **동작**:
  - 클릭 시 선택된 옵션과 함께 장바구니에 추가
  - 성공 시 피드백 (토스트 메시지 또는 버튼 애니메이션)

## 5. 인터랙션 설계

### 5.1 버튼 인터랙션

#### 5.1.1 담기 버튼
- **클릭 시**:
  1. 선택된 옵션 확인
  2. 장바구니에 항목 추가
  3. 성공 피드백 표시 (토스트 메시지: "장바구니에 추가되었습니다")
  4. 장바구니 카운트 업데이트
  5. 장바구니 섹션 표시 (숨겨져 있었다면)

#### 5.1.2 주문하기 버튼
- **클릭 시**:
  1. 장바구니 항목 확인
  2. 주문 페이지로 이동 또는 주문 생성 API 호출
  3. 로딩 상태 표시
  4. 성공 시 주문 확인 페이지로 이동

### 5.2 옵션 선택 인터랙션

#### 5.2.1 체크박스 선택
- **체크 시**:
  - 체크박스 상태 변경
  - 옵션 가격이 제품 가격에 반영 (선택사항, 실시간 업데이트)
- **언체크 시**:
  - 체크박스 상태 변경
  - 옵션 가격 제거

### 5.3 장바구니 인터랙션

#### 5.3.1 항목 추가
- 장바구니에 항목이 추가되면:
  - 장바구니 섹션이 자동으로 표시됨 (스크롤하여 보이도록)
  - 총 금액이 자동으로 업데이트됨
  - 애니메이션 효과 (선택사항)

#### 5.3.2 항목 삭제
- 삭제 버튼 클릭 시:
  - 확인 다이얼로그 표시 (선택사항)
  - 항목 제거
  - 총 금액 업데이트
  - 장바구니가 비면 장바구니 섹션 숨김

## 6. 반응형 디자인

### 6.1 브레이크포인트

- **Mobile**: 320px ~ 767px
- **Tablet**: 768px ~ 1023px
- **Desktop**: 1024px 이상

### 6.2 레이아웃 조정

#### 6.2.1 Mobile (320px ~ 767px)
- **제품 카드**: 
  - 1열 레이아웃 (세로 스크롤)
  - 카드 너비: 100% - 32px (좌우 패딩)
- **헤더**: 
  - 브랜드명 폰트 크기: 20px
  - 버튼 크기: 작게 조정
- **장바구니**: 
  - 하단 고정 또는 스크롤 가능
  - 항목 정보 간소화

#### 6.2.2 Tablet (768px ~ 1023px)
- **제품 카드**: 
  - 2열 레이아웃
  - 카드 너비: 48% (간격 포함)
- **장바구니**: 
  - 사이드바 또는 하단 고정

#### 6.2.3 Desktop (1024px 이상)
- **제품 카드**: 
  - 3열 이상 레이아웃
  - 카드 너비: 30% ~ 33% (간격 포함)
- **장바구니**: 
  - 사이드바 또는 하단 고정
  - 더 넓은 레이아웃

## 7. 접근성

### 7.1 키보드 네비게이션
- 모든 인터랙티브 요소는 키보드로 접근 가능
- Tab 키로 포커스 이동
- Enter/Space로 버튼 클릭
- 체크박스는 Space로 토글

### 7.2 스크린 리더 지원
- 모든 이미지에 alt 텍스트 제공
- 버튼과 링크에 명확한 aria-label
- 폼 요소에 적절한 label 연결

### 7.3 색상 대비
- 텍스트와 배경의 대비 비율: WCAG AA 기준 준수 (4.5:1 이상)
- 색상만으로 정보를 전달하지 않음 (아이콘 또는 텍스트 병행)

### 7.4 포커스 표시
- 모든 포커스 가능한 요소에 명확한 포커스 표시
- 포커스 링: 2px solid Primary Color

## 8. 성능 요구사항

### 8.1 로딩 성능
- **초기 로딩 시간**: 2초 이내
- **이미지 로딩**: Lazy loading 적용
- **코드 스플리팅**: 라우트별 코드 분할

### 8.2 인터랙션 성능
- **버튼 클릭 응답**: 100ms 이내 피드백
- **장바구니 업데이트**: 즉시 반영 (50ms 이내)
- **스크롤 성능**: 60fps 유지

### 8.3 최적화
- **이미지 최적화**: WebP 형식, 적절한 크기
- **번들 크기**: 초기 번들 200KB 이하
- **캐싱**: 정적 자산 캐싱 전략

## 9. 상태 관리

### 9.1 전역 상태
- **장바구니 상태**: Zustand 또는 Context API

## 10. 에러 처리

### 10.1 에러 메시지
- **네트워크 에러**: "연결에 실패했습니다. 다시 시도해주세요."
- **주문 실패**: "주문 처리 중 오류가 발생했습니다."
- **재고 부족**: "일시적으로 품절되었습니다."
